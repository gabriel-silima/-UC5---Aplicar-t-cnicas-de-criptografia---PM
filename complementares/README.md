# Materiais complementares

Estes exemplos não são anexos identificados no Classroom:

- [rsa_uc5_demo.py](rsa/rsa_uc5_demo.py)
- [rsa_uc5_menu.py](rsa/rsa_uc5_menu.py)

Requerem Python 3.9 ou superior e somente a biblioteca padrão. RSA didático com primos pequenos e sem padding, usado para observar a matemática.

A partir da raiz do repositório, execute no PowerShell:

```powershell
py -3 .\complementares\rsa\rsa_uc5_menu.py
```

O arquivo original `CriptoPrimos.py` está na publicação de números primos no mural. Seu limite de um bilhão e a construção da lista completa podem consumir muita memória e tempo; ele foi preservado sem execução nesta organização.
