# Números primos e RSA

[Voltar ao início](../README.md) · [Catálogo completo](../catalogo/README.md)

Os dois exemplos RSA são materiais complementares do laboratório. Os primos pequenos e o RSA sem padding servem para observar a matemática, sem proteção de dados reais.

Para executar no Windows, a partir da raiz do repositório:

```powershell
py -3 .\06-numeros-primos-rsa\codigos\rsa_uc5_menu.py
```

Em Linux/macOS:

```bash
python3 06-numeros-primos-rsa/codigos/rsa_uc5_menu.py
```

Requer Python 3.9 ou superior; os scripts usam apenas a biblioteca padrão. O `CriptoPrimos.py` original foi preservado: seu limite é 1.000.000.000 e a compreensão de lista percorre todos os números antes de recortar a amostra de 80. Isso pode consumir muita memória e tempo. Nenhuma execução desse script pesado foi feita na organização do acervo.
